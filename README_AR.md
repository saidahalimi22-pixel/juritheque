# نشر المرصد المغربي للأبحاث والدراسات القانونية على Vercel (مجاناً، بلا بطاقة بنكية)

الموقع + الـ API + لوحة الإدارة تعمل كلها على **رابط واحد**:
- **Vercel**: يستضيف الواجهة والـ API.
- **Neon**: قاعدة البيانات (عندك حساب).
- **Vercel Blob**: تخزين ملفات PDF (من نفس حساب Vercel).

## الخطوة 1 — قاعدة بيانات Neon (جديدة وفارغة)
1. في Neon أنشئ **Project جديداً** (أو Branch جديداً فارغاً). لا تستعمل قاعدة قديمة فيها جداول.
2. من زر **Connect** انسخ رابطين:
   - مع تفعيل **Connection pooling** → هذا هو `DATABASE_URL`
   - مع إلغاء التفعيل (Direct) → هذا هو `DIRECT_URL`

## الخطوة 2 — رفع الملفات إلى GitHub
1. أنشئ مستودعاً جديداً (مثلاً `juritheque-app`).
2. **Add file → Upload files** ثم اسحب **محتويات** هذا المجلد (api، public، prisma، scripts، package.json، vercel.json، .gitignore) واضغط Commit.

## الخطوة 3 — Vercel
1. **Add New → Project** واختر المستودع. اترك Framework على **Other** ولا تغيّر أوامر البناء.
2. افتح **Environment Variables** وأضف قبل الضغط على Deploy:

| الاسم | القيمة |
|---|---|
| `DATABASE_URL` | الرابط الأول من Neon |
| `DIRECT_URL` | الرابط الثاني من Neon |
| `JWT_SECRET` | نص عشوائي طويل (40 حرفاً أو أكثر) |
| `SETUP_KEY` | كلمة سرية مؤقتة من اختيارك |
| `ADMIN_EMAIL` | بريدك كمدير |
| `ADMIN_PASSWORD` | كلمة مرور قوية (8 أحرف فأكثر) |

3. اضغط **Deploy**. أثناء البناء تُنشأ الجداول في Neon تلقائياً.

## الخطوة 4 — تفعيل رفع الملفات
في مشروعك على Vercel: **Storage → Create → Blob** → اربطه بالمشروع، ثم **Deployments → Redeploy**.

## الخطوة 5 — إنشاء حساب المدير
1. افتح `https://رابط-موقعك/api/health` فيجب أن يظهر `status: ok`.
2. افتح `https://رابط-موقعك/api/setup?key=SETUP_KEY&sample=1` (ضع قيمة المفتاح الذي اخترته). يُنشئ المدير ويضيف محتوى تجريبياً. احذف `&sample=1` إن لم تُرد محتوى تجريبياً.
3. من الموقع اضغط **دخول** بالبريد وكلمة المرور، ثم **الإدارة**.
4. بعدها احذف `SETUP_KEY` و`ADMIN_PASSWORD` من Vercel وأعد النشر.

## الاستعمال
- **الإدارة → القسم → إضافة**: أدخل البيانات واختر ملف PDF فيُرفع ويُربط بالمرجع.
- الزائر يتصفح العناوين، و**التحميل للأعضاء المسجلين فقط**.
- حدّ الرفع الأول 3 ميغابايت عبر الخادم؛ الأكبر يُرفع مباشرة إلى Blob. إن تعذّر، ضع رابط الملف يدوياً في خانة الرابط.

## المساعد الذكي (لاحقاً)
أضف في Vercel: `AI_API_KEY` و`AI_BASE_URL` و`AI_MODEL` (أي خدمة متوافقة مع واجهة OpenAI، ومنها خدمات لها خطة مجانية). بدون المفتاح يعرض المساعد رسالة "غير مفعّل".

## إن ظهرت مشكلة
| العرض | الحل |
|---|---|
| فشل البناء عند `prisma db push` | تأكد من `DATABASE_URL` و`DIRECT_URL` وأن القاعدة فارغة |
| "مخزن الملفات غير مفعّل" | الخطوة 4 ثم Redeploy |
| خطأ 500 | Vercel → Logs وأرسل لي النص |
| نسيت كلمة مرور المدير | أعد إضافة `SETUP_KEY` و`ADMIN_PASSWORD` ثم افتح رابط setup |
