# Jurithèque - المنصة القانونية الذكية

## نظرة عامة
منصة قانونية إلكترونية متكاملة تحتوي على:
- المكتبة القانونية (مدونة القوانين، الكتب، الرسائل والأطروحات، المقالات، التقارير)
- الاجتهادات القضائية
- المحاضرات والتكوينات
- الإعلانات
- المساعد القانوني الذكي

## الألوان المستخدمة
- الأزرق الملكي: `#0A2540`
- الذهبي: `#C9A84C`
- الأبيض: `#FFFFFF`

## كيفية تشغيل النسخة الحالية (الواجهة)
1. قم بفتح ملف `index.html` مباشرة في المتصفح
2. أو استخدم خادم محلي:
   ```bash
   cd juritheque
   python3 -m http.server 8080
   ```
   ثم افتح: http://localhost:8080

## تحويلها إلى منصة حقيقية (الخطوات التالية)

### 1. التقنية المقترحة (موصى بها)
| الطبقة | التقنية |
|--------|---------|
| Frontend | Next.js 14+ (App Router) + Tailwind CSS + TypeScript |
| Backend | NestJS أو Laravel 11 |
| قاعدة البيانات | PostgreSQL |
| البحث | Meilisearch أو Elasticsearch (مهم جداً للنصوص القانونية) |
| الملفات | AWS S3 أو MinIO (لرفع PDF القوانين والكتب) |
| المصادقة | NextAuth.js أو Laravel Sanctum |
| المساعد الذكي | ربط بـ Grok API أو OpenAI + RAG على محتوى المنصة |
| الاستضافة | Vercel (Frontend) + Railway/DigitalOcean (Backend) |

### 2. الميزات الأساسية للمنصة الحقيقية
- نظام مستخدمين (زائر / مشترك / محامي / إداري)
- رفع وإدارة الملفات PDF
- بحث متقدم (نص كامل + فلاتر)
- لوحة تحكم للإدارة
- نظام اشتراكات (اختياري)
- ربط حقيقي بالمساعد الذكي مع استرجاع من قاعدة البيانات (RAG)
- إشعارات للإعلانات الجديدة

### 3. هيكل قاعدة البيانات المقترح (مختصر)
- users
- categories
- laws (مدونة القوانين)
- books
- theses
- articles
- reports
- jurisprudence (الأحكام)
- lectures
- announcements
- chat_sessions / chat_messages

### 4. المساعد القانوني الذكي (النسخة الحقيقية)
يتم بناؤه باستخدام تقنية **RAG** (Retrieval-Augmented Generation):
1. تخزين كل النصوص والأحكام في قاعدة بيانات + محرك بحث
2. عند سؤال المستخدم → البحث عن النصوص ذات الصلة
3. إرسال النصوص + السؤال إلى نموذج الذكاء الاصطناعي
4. إرجاع إجابة مستندة إلى المصادر الحقيقية مع روابط
