# هيكل المساعد القانوني الذكي (RAG Architecture)
## Jurithèque AI Legal Assistant

---

## 1. ما هو RAG؟

**RAG = Retrieval-Augmented Generation**

بدلاً من أن يجيب نموذج الذكاء الاصطناعي من ذاكرته فقط (مما قد يؤدي إلى هلوسات)، نقوم بـ:

1. **استرجاع** النصوص والأحكام ذات الصلة من قاعدة بيانات المنصة
2. **إرسالها** مع سؤال المستخدم إلى نموذج الذكاء الاصطناعي
3. **توليد** إجابة مستندة إلى المصادر الحقيقية مع ذكر المراجع

---

## 2. المخطط العام

```
[سؤال المستخدم]
       │
       ▼
[1. فهم السؤال + استخراج الكلمات المفتاحية]
       │
       ▼
[2. البحث في قاعدة البيانات / محرك البحث]
   ├── قوانين
   ├── اجتهادات قضائية
   ├── مقالات وكتب ورسائل
       │
       ▼
[3. اختيار أفضل 5-10 نتائج (Context)]
       │
       ▼
[4. بناء الـ Prompt]
   "أنت مساعد قانوني... 
    هذه هي المصادر:
    1. [قانون ...]
    2. [قرار ...]
    السؤال: ...
    أجب بناءً على المصادر فقط واذكر المراجع."
       │
       ▼
[5. إرسال إلى نموذج AI (Grok / GPT / Claude...)]
       │
       ▼
[6. عرض الإجابة + روابط المصادر للمستخدم]
```

---

## 3. المكونات التقنية المطلوبة

| المكون | التقنية المقترحة | الدور |
|--------|------------------|------|
| **محرك البحث** | Meilisearch أو Elasticsearch أو Typesense | بحث سريع ودقيق في النصوص |
| **قاعدة البيانات** | PostgreSQL (التي صممناها) | تخزين البيانات الوصفية + النصوص |
| **تخزين الملفات** | S3 / MinIO / محلي | ملفات PDF |
| **نموذج الذكاء الاصطناعي** | Grok API أو OpenAI أو Claude | توليد الإجابة |
| **Backend** | NestJS / Laravel / FastAPI | تنسيق العملية |
| **Frontend** | الصفحة الحالية `assistant.html` | واجهة الدردشة |

## 4. خطوات التنفيذ العملية

### المرحلة أ: إعداد محرك البحث (Meilisearch مثال)

```bash
# تشغيل Meilisearch بـ Docker
docker run -d \
  --name meilisearch \
  -p 7700:7700 \
  -e MEILI_MASTER_KEY=juritheque_master_key \
  getmeili/meilisearch:latest
```

### المرحلة ب: فهرسة المحتوى

عند إضافة أي قانون أو حكم أو مقال، يتم إرسال البيانات إلى Meilisearch:

```json
{
  "id": "uuid-...",
  "type": "law",
  "title": "الأمر رقم 75-58 المتضمن القانون المدني",
  "content": "النص الكامل أو الملخص...",
  "category": "القانون المدني",
  "date": "1975-09-26",
  "url": "/laws/uuid-..."
}
```

### المرحلة ج: عند وصول سؤال

```javascript
// مثال مبسط (Node.js)
async function askLegalAssistant(question, sessionId) {
  // 1. البحث عن مصادر ذات صلة
  const searchResults = await meilisearch.index('documents').search(question, {
    limit: 8,
    attributesToRetrieve: ['id', 'type', 'title', 'content', 'url']
  });

  // 2. بناء السياق
  const context = searchResults.hits.map((hit, i) => 
    `[مصدر ${i+1}] (${hit.type}) ${hit.title}\n${hit.content.substring(0, 1500)}`
  ).join('\n\n');

  // 3. بناء الـ Prompt
  const systemPrompt = `أنت مساعد قانوني متخصص في القانون الجزائري.
أجب على سؤال المستخدم بالاعتماد فقط على المصادر المقدمة أدناه.
إذا لم تجد معلومة كافية، قل ذلك بوضوح.
اذكر دائماً رقم المصدر الذي اعتمدت عليه.

المصادر:
${context}`;

  // 4. استدعاء نموذج AI
  const answer = await callAI({
    system: systemPrompt,
    user: question
  });

  // 5. حفظ المحادثة + إرجاع الإجابة مع المصادر
  return {
    answer,
    sources: searchResults.hits.map(h => ({
      type: h.type,
      title: h.title,
      url: h.url
    }))
  };
}
```

## 5. هيكل الـ Prompt الموصى به

```
أنت مساعد قانوني محترف متخصص في التشريع والاجتهاد القضائي الجزائري.
مهمتك:
- الإجابة بدقة ووضوح باللغة العربية الفصحى
- الاعتماد فقط على المصادر المقدمة
- ذكر المراجع (رقم القانون أو رقم القرار)
- إذا كان السؤال خارج نطاق المصادر، قل: "لا تتوفر لدي معلومات كافية في قاعدة البيانات الحالية حول هذا الموضوع"

المصادر المتاحة:
----------------
{context}
----------------

سؤال المستخدم: {question}
```

## 6. تحسينات متقدمة (لاحقاً)

1. **إعادة ترتيب النتائج (Re-ranking)** باستخدام نموذج متخصص
2. **تقسيم النصوص الطويلة (Chunking)** للقوانين الكبيرة
3. **Embeddings** (تمثيل دلالي) لبحث أفضل من الكلمات المفتاحية فقط
4. **ذاكرة المحادثة** لفهم الأسئلة المتتابعة
5. **تصفية حسب الصلاحيات** (محتوى للمشتركين فقط)

---

## 7. ملاحظات أمنية وقانونية

- لا تقدم استشارات قانونية ملزمة. أضف دائماً تنويهاً:  
  «هذه الإجابة لأغراض إعلامية فقط ولا تُعتبر استشارة قانونية.»
- لا تخزن بيانات شخصية حساسة في سجلات المحادثات بدون موافقة
- راقب التكاليف عند استخدام APIs مدفوعة

---

## 8. الخطوات التالية للتنفيذ

1. تشغيل Meilisearch
2. كتابة سكربت لفهرسة القوانين والاجتهادات الموجودة
3. إنشاء API endpoint: `POST /api/assistant/ask`
4. ربط واجهة `assistant.html` بهذا الـ API
5. اختبار جودة الإجابات وتحسين الـ Prompt

---

**الخلاصة:**  
المساعد الذكي ليس مجرد دردشة عامة، بل نظام يسترجع أولاً من مكتبتك القانونية ثم يجيب. هذا يجعله موثوقاً ومفيداً حقاً للمستخدمين.
